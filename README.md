# Hurricane Preparedness App

## Run the project

Requirements:
- Node.js
- npm
- Expo Go
- Expo SDK 57
- Expo Go must be updated to a version compatible with Expo SDK 57

Install dependencies:

```bash
npm install
```

Start the project:

```bash
npx expo start
```

A QR code will be displayed in the terminal, scan it with the Expo Go app on your mobile device.

## Run tests

```bash
npm test
```
